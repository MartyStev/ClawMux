# Security Policy

If you discover a security issue in ClawMux, please report it responsibly.

## Reporting

Preferred reporting channels:

- email: `security@martystev.dev`
- create a GitHub issue and tag it with `security`
- use GitHub Security Advisories if available in this repository

Please include a clear description, reproduction steps, and any affected versions.

Do not publish details publicly until the issue is resolved.

## Supported versions

We will respond to security reports for the current release and the previous minor release.

## Response time

We aim to acknowledge new reports within 72 hours.

## Thank you

Your reports help keep ClawMux safe for everyone.
